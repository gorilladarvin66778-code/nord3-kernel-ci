# nord3-kernel-ci

OnePlus Nord 3 – RTL8821AU Wi-Fi Driver Project

This project aims to enable the TP-Link Archer T2U Plus (Realtek RTL8821AU) USB Wi-Fi adapter to work on the OnePlus Nord 3 through USB OTG.

Device & Software

- Phone: OnePlus Nord 3 (MT6983)
- ROM: LineageOS 22.2 (Android 15)
- Kernel: Linux 5.10.209
- Adapter: TP-Link Archer T2U Plus
- Chipset: Realtek RTL8821AU
- USB ID: 2357:0120
- Root: Magisk

Project Goal 🎯

Build a compatible RTL8821AU kernel module for the phone's existing kernel, test USB Wi-Fi functionality, and achieve stable operation without unnecessary kernel modifications.

# Status: Work in progress – Kernel module build and compatibility testing are ongoing.
